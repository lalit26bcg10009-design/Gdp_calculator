# Gdp_calculator
GDP Calculator (Python)  This project is a simple Python program that calculates a country's Gross Domestic Product (GDP), the total value of all goods and services an economy produces in a given period. You enter a few basic economic figures, and the program does the math and shows the result clearly.
 
# GDP Calculator

Simple python program to calculate GDP using different methods. Runs in terminal.

## Features
- Expenditure method (C + I + G + X - M)
- Income method
- Real GDP using deflator
- GDP growth rate
- Per capita GD  
- Saves history of calculations

## How to run

```
python gdp_calculator.py
```

Or double click `Run GDP Calculator.bat`

## Requirements
- Python 3
